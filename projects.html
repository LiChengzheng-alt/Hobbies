Object-oriented programming

Uses object-oriented programming to manage smart plug devices.

Difficulty: Intermediate

  • Store devices attributes like ID, name, and power consumption.
  • Tracks all plugs to compute metrics like average power consumption, find the highest-rated plug, and support adding, retrieving, or deleting records.
  • Demonstrates these features through the terminal, creating initial sample plugs, displaying outputs like average watts for power plugs, prompting the user to dynamically add or look up devices, and updating the active record list upon deletion.

Data Processing

Parses data from sales.txt inside the DataFiles folder.

Difficulty: Intermediate

  • It parses employee details like calculating their age using the datetime module and computing total sales revenue and commission.
  • It automatically creates a directory structure like SalesData, SalesReports, TopPerformers. It stores performance reports, separating high earners who make $15,000 or more into an elite_sales.txt report while saving other employees to a standard_sales.txt file.
  • Finally, it reads back and displays the processed records directly in the terminal console.

Automated File Manager

It is designed to inspect directory contents with a large number of files.

Difficulty: Intermediate

  • It iterates through .txt files in the directory to measure file sizes (in bytes), prints them, calculates the total and average file sizes.
  • It converts all .png files to .jpg files using the os.path library.
  • It loops through text files (e.g., coffee.txt) and renames them using a numeric counter scheme (e.g., coffee11.txt, coffee12.txt, etc.).
